# 知航 AI 家庭学习系统 — Production 6.0

只供家庭自用的高中 AI 学习系统。学生端负责计划、拍题、试卷、错题、预习复习、训练、画像与教材知识库；家长端只展示由学生真实学习快照生成的图表和明细。

## Production 6.0 正式启用版

- **真实接口模式**：前端不再提供 Demo、Mock API 或失败后假数据回退；缺少 API 配置或接口失败时明确报错。
- **正式数据清理**：首次运行数据库迁移时清除学习快照、学习记录和画像分析，保留用户账号、家庭绑定、教材导入任务、知识条目与 R2 原文件。
- **34 册教材目录**：前后端使用同一套六科 34 册固定目录，支持正式书名、别名和文件名自动匹配。
- **教材任务闭环**：显示真实文件处理进度、知识条目数量、未匹配状态；支持重新解析和手动绑定书册。
- **安全重新解析**：旧知识库保留到新解析完整写入成功后再替换，解析失败不会先清空已有结果。
- **家长真实同步**：学习计划、学习周期、完成状态、时长、错题、小测和知识掌握通过学生快照同步；家长端不读取旧缓存兜底。
- **简洁图表首页**：三项核心指标和四块主要图表，数据不足时显示空状态，不补造趋势或指标。
- **私人家庭账号**：关闭公开注册、绑定码和解除固定家庭绑定；账号由服务端环境变量创建和维护。

## 核心学习能力

- 答案保护与分层提示，多次尝试后才开放完整推导。
- 错题自动入库、错因诊断、重新作答、换讲法、迁移检测与闭环验证。
- 预习、复习、专项小练、整套模拟卷和考前冲刺。
- 教材、练习册、真题、题库和讲义统一进入家庭 R2 知识库。
- 视觉模型处理图片、公式和试卷；文本模型处理讲解、计划、出题与学习分析。

## 固定高中教材版本

- 语文：人教版（统编版）
- 数学：人教版 A 版
- 英语：外研版（新标准）
- 历史：人教版（统编版）
- 地理：人教版
- 思想政治：人教版（统编版）

代码只保存书目、章节目录、来源入口和导入能力，不打包教材 PDF。

## 本地完整检查

```bash
npm ci
npm --prefix backend ci
npm run check
```

单独运行不依赖外部服务的正式版源码验证：

```bash
npm run test:source
```

## 部署

- 前端：`.github/workflows/deploy-student.yml` 与 `.github/workflows/deploy-parent.yml`
- 后端：`render.yaml`
- GitHub 仓库变量：`VITE_API_BASE_URL`
- GitHub Secrets：`CLOUDFLARE_API_TOKEN`、`CLOUDFLARE_ACCOUNT_ID`
- Render：配置 PostgreSQL、固定家庭账号、Qwen/DeepSeek 与 R2 环境变量；部署前会执行一次性正式数据清理迁移。
