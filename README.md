# 知航 AI 家庭学习系统 — Final 5.0

只供家庭自用的高中 AI 学习系统。学生端负责计划、拍题、试卷、错题、预习复习、训练、画像与资料；家长端用图表查看计划执行、学科掌握、错因、订正闭环、有效讲法和阶段趋势。

## Final 5.0：自适应讲解与错题闭环

1. **错误后不直接泄露答案**：第一次、第二次作答优先给诊断、分层提示和换讲法；达到设置次数仍未答对，才开放完整答案与推导。
2. **错题自动入库**：拍题、日常小测、模拟训练中的错题自动进入错题本，保留原题、原答案、错因、尝试记录和使用过的讲法。
3. **多种讲法切换**：启发提问、生活类比、图像框架、公式推导、步骤拆解、反例辨析至少提供多种路径，不用同一套模板硬讲。
4. **重答与迁移验证**：答对原题后还要完成一道变式题；只有迁移检测通过，错题才标记为“已验证”。
5. **有效讲法画像**：记录真正帮助学生通过迁移检测的方法，按科目、讲法、成功率和使用次数调整后续推荐。
6. **家长端闭环图表**：直观看到待订正、订正中、待验证、已验证，以及不同讲法的有效率。

## 其他完整能力

- **今日计划置顶**：预习 → 复习 → 训练按顺序执行，切换页面保留状态。
- **教材优先知识库**：先选科目与教材书册，再按章节导入、检索和生成内容。
- **预习与复习**：教材 → 章节两步选择，也支持自定义章节、重点问题和个人要求。
- **三种训练**：专项小练、整套模拟卷、考前冲刺；可选题量、题型、难度、题源、书册和章节。
- **学生画像**：画像小测与错题订正、迁移检测、试卷、训练、复习和计划执行共同构建。
- **R2 资料链路**：支持教材/练习册 ZIP 上传、远程 HTTPS 文件导入、自动处理和知识条目检索。
- **视觉与文本模型分工**：视觉模型处理图片、公式和试卷；文本模型处理讲解、计划、出题与分析。

## 固定高中教材版本

- 语文：人教版（统编版）
- 数学：人教版 A 版
- 英语：外研版（新标准）
- 历史：人教版（统编版），含《中外历史纲要》上、下册
- 地理：人教版
- 思想政治：人教版（统编版）

代码中保存书目、章节目录、来源入口和导入能力，不直接打包教材 PDF。

## 部署

- 前端：`.github/workflows/deploy-student.yml` 与 `deploy-parent.yml`
- 后端：`render.yaml`
- GitHub 仓库变量：`VITE_API_BASE_URL`
- GitHub Secrets：`CLOUDFLARE_API_TOKEN`、`CLOUDFLARE_ACCOUNT_ID`
- Render：根据 `render.yaml` 配置数据库、视觉/文本模型与 R2 环境变量。

## 资料补齐方式

资料页按科目、教材和书册显示已导入与缺失状态。可将家庭已有教材、练习册、真题和校内资料按书册上传，也可粘贴受支持的 HTTPS 文件直链导入。导入后按 `bookId + chapter + resourceKind` 检索，预习、复习和训练不会跨书册乱取内容。
