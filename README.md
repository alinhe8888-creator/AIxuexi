# 知航 AI 家庭学习系统 — Final 4.0

只供家庭自用的高中 AI 学习系统。学生端负责计划、拍题、试卷、错题、预习复习、模拟训练、画像和资料；家长端用图表查看计划执行、学科掌握、错因、复习状态和阶段趋势。

## 已完成的核心闭环

1. **今日计划置顶**：预习 → 复习 → 训练按顺序执行，切换页面保留状态。
2. **教材优先知识库**：先选科目与教材书册，再按章节导入、检索和生成内容。
3. **预习与复习**：教材 → 章节两步选择，也支持自定义章节、问题和个人要求。
4. **模拟训练**：专项小练、整套模拟卷、考前冲刺；可选题量、题型、难度、题源、书册和章节。
5. **学生画像**：画像小测与真实学习证据共同构建，不以一次答错直接贴标签。
6. **家长图表看板**：学科柱状图、能力雷达、掌握分布、学习热力图、复习状态、错因和小测趋势。
7. **R2 资料链路**：支持教材/练习册 ZIP 上传、远程 HTTPS 文件导入、自动处理和知识条目检索。
8. **Qwen 3.7 + DeepSeek V4 分工**：Qwen Vision 处理图片和试卷；文本任务优先 DeepSeek，未配置时回退 Qwen。

## 固定高中教材版本

- 语文：人教版（统编版）
- 数学：人教版 A 版
- 英语：外研版（新标准）
- 历史：人教版（统编版），含《中外历史纲要》上、下册
- 地理：人教版
- 思想政治：人教版（统编版）

代码中保存的是书目、章节目录、来源链接和导入能力，不直接打包教材 PDF。

## 部署

- 前端：`.github/workflows/deploy-student.yml` 与 `deploy-parent.yml`
- 后端：`render.yaml`
- GitHub 仓库变量：`VITE_API_BASE_URL`
- GitHub Secrets：`CLOUDFLARE_API_TOKEN`、`CLOUDFLARE_ACCOUNT_ID`
- Render：根据 `render.yaml` 配置数据库、Qwen、DeepSeek 与 R2 环境变量。

## 资料补齐方式

资料页会显示每个科目的完整书册目录和缺失状态。可将家庭已有教材、练习册、真题和校内资料按书册上传；也可粘贴受支持的 HTTPS 文件直链导入。导入后系统按 `bookId + chapter + resourceKind` 检索，预习、复习和训练不会跨书册乱取内容。
